# webgl-seascape-video

A clean-room, from-scratch re-implementation of the idea behind **[holooooo/webgl-seascape-video](https://github.com/holooooo/webgl-seascape-video)** by [@holooooo](https://github.com/holooooo). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
